## Why FluxDM?

**A clean, familiar desktop download manager. Powered by a native Go engine. Free, with zero telemetry.**

| | FluxDM | Traditional Paid Download Managers |
| --- | --- | --- |
| Multi-part download engine | **Native Go 1.24 (`dm_engine`)** | Proprietary |
| Protocols | **HTTP, HTTPS, FTP, Torrents &amp; Magnet** | HTTP/HTTPS/FTP only |
| Video &amp; Link Grabber | **Built-in** | Limited or separate tools |
| RSS Feeds &amp; Auto-Extract | **Built-in** | Usually missing |
| Themes | **9 Dark &amp; Light themes** | Classic / limited skins |
| Languages &amp; RTL | **41 languages (full RTL support)** | Varies |
| Price | **Free, forever** | Paid, after a 30-day trial |
| Ads, nag screens, telemetry | **None — 100% local** | Registration &amp; nag screens |
| Source code | **Open on GitHub** | Closed source |

Nothing new to learn: the toolbar, sidebar categories, download list, progress window, scheduler, and speed limiter are right where you expect them.

## What it does

- **Speeds up every download** with multi-part segmented HTTP/HTTPS and FTP downloading powered by a dedicated Go 1.24 engine (`dm_engine.exe`).
- **Pause and resume** downloads cleanly without starting over, with saved progress recovery and a one-click **Stop All** action.
- **Browser integration &amp; clipboard monitoring**: listens on a local bridge (`127.0.0.1:45821`) and watches your clipboard for supported links, working alongside Chrome, Edge, Brave, Firefox, Opera, Vivaldi, Floorp, and Safari.
- **Torrents, magnet links &amp; RSS feeds**: parse `.torrent` files, pick the files you want, configure torrent settings, and follow RSS feeds right inside FluxDM.
- **Video &amp; Link Grabber**: scan web pages to collect downloadable links or grab videos directly.
- **Automatic archive extraction**: extract downloaded archives automatically as soon as they finish.
- **Smart categories &amp; sidebar**: automatically sorts files into categories by extension with live item counts and collapsible sidebar visibility.
- **Scheduler &amp; queues**: schedule downloads to start and stop automatically at the times you choose.
- **Speed limiter**: cap a single download or all downloads so your browsing and calls stay smooth.
- **Proxy, Site Logins &amp; Debrid**: configure custom connection limits per server, authenticated site credentials, and debrid accounts.
- **9 built-in themes + Dark &amp; Light mode**: switch between **Classic, Native, High contrast, Metro, Adwaita, Breeze, Luna, Aero, and Aqua** in either dark or light mode.
- **41 languages with full RTL**: instant language switching with mirrored right-to-left UI for Persian, Arabic, Hebrew, and Urdu.
- **No ads, no trial, no telemetry**: FluxDM runs 100% locally on your machine and never tracks your downloads.

## For developers

<details>
<summary><b>Build from source</b></summary>

### Prerequisites

- **Windows 10 / 11 (x64)**
- [Flutter SDK](https://docs.flutter.dev/get-started/install/windows/desktop) (Dart SDK `^3.14.0`) with Windows desktop support &amp; Visual Studio C++ build tools
- [Go 1.24+](https://go.dev/dl/)
- [Inno Setup 6](https://jrsoftware.org/isinfo.php) (optional, only needed to compile `FluxDM-Setup-1.0.0.exe`; install via `winget install JRSoftware.InnoSetup`)

### Run in development

```powershell
# 1. Build the Go download engine
cd go_backend
go build -o dm_engine.exe .
cd ..

# 2. Fetch Flutter packages and run on Windows
flutter pub get
flutter run -d windows
```

### Run tests

```powershell
# Flutter / Dart tests
flutter test

# Go engine tests
cd go_backend
go test ./...
```

### Build the Windows installer

Run the automated build script to compile `dm_engine.exe`, build the Flutter Windows release bundle, and package `installer/output/FluxDM-Setup-1.0.0.exe`:

```powershell
.\installer\build_installer.ps1
```

</details>

<details>
<summary><b>Architecture &amp; project layout</b></summary>

FluxDM separates the user interface from the download engine: the **Flutter desktop app** communicates with the local **Go engine (`dm_engine.exe`)** over loopback HTTP for high-throughput, low-overhead I/O.

| Path | What it is |
| --- | --- |
| [`lib/app`](lib/app) | Application entrypoint, `DownloadManagerApp`, and routing |
| [`lib/core/localization`](lib/core/localization) | 41-language translation tables and RTL directionality (`AppStrings`) |
| [`lib/core/theme`](lib/core/theme) | 9 Dark/Light theme palettes (`AppThemeController`) |
| [`lib/core/widgets`](lib/core/widgets) | Main window, top menu bar, toolbar, header, and collapsible sidebar |
| [`lib/features/downloads`](lib/features/downloads) | Download controller, progress window, scheduler, speed limiter, link/video grabber, and local browser bridge (`127.0.0.1:45821`) |
| [`lib/features/torrents`](lib/features/torrents) | `.torrent` parser, add-torrent dialog, torrent settings, and RSS feed manager |
| [`lib/features/settings`](lib/features/settings) | Configuration dialog, site logins, connection exceptions, debrid &amp; sound events |
| [`go_backend/internal/api`](go_backend/internal/api) | Local HTTP API server (`/api/probe`, `/api/downloads/stream`, `/api/torrent/parse`, `/api/rss/fetch`, `/api/archive/extract`, `/api/grab/links`, `/api/grab/video`) |
| [`go_backend/internal/engine`](go_backend/internal/engine) | Segmented HTTP/HTTPS downloader, FTP client, smart dialer, speed limiter, torrent/RSS/archive/grabber modules |
| [`installer`](installer) | Inno Setup 6 script (`FluxDM.iss`), build automation (`build_installer.ps1`), and EULA |

</details>
